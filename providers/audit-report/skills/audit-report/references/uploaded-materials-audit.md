# 上传资料逐项目核查要求

以下要求补充现有报告模板，不能替代或删减完整的 R01-R19 内置规则。

## 每项目逐份资料核查

先从报告中识别全部检测项目。对每个检测项目，逐一检查本次提交的每份检测标准、设备台账及其他资料，不得只挑选看似相关的文件。每份资料使用唯一引用 ID（`M01`、`M02`……）和原文件名；即使文件名相同，也必须分别审阅和分别出现在矩阵中。输出“检测项目 × 全部资料引用 ID”矩阵，每个单元格说明该资料的具体要求或记录、是否适用、核查结果、依据及理由。不适用时必须解释原因；资料缺失、内容不清或不足以判断时明确说明限制，不能将其默认为符合。

标准名称、编号、年份及条款对应均由模型依据已提交资料判断。只有资料实际给出规范条文时才可以陈述具体条款要求；仅有 Excel 标准目录、名称或编号时，不得推造条款、限值或判定条件，也不得据目录声称满足/违反标准。说明可核实的来源、无法核实的范围和所需补充材料。不同资料冲突或版本差异应分别引用来源并说明影响，不能自行消解冲突。

## 设备台账与报告字段

按报告中的检测编号、设备使用记录和设备编号匹配具体台账记录，不得仅凭名称或型号猜测。逐项并列报告记载值、台账实际值、来源位置及一致性结论，报告设备编号和台账设备编号必须是两个独立字段。覆盖设备名称、编号、型号规格、校准日期、校准有效期及可用状态（资料实际包含的字段）。台账记录优先以资料引用 ID、原文件名、工作表、可唯一定位的原始设备编号及所引原值定位；不强制在输出中重述行号或单元格坐标。若自愿引用资料解析提供的坐标，必须逐字照录完整坐标/范围及对应原值，不得从 A 列序号、筛选后的顺序或相邻记录推算，也不得用范围起始单元格代替实际值所在位置。不同编号以及数字换位必须逐位核实，不能视为同一设备；不得模糊合并。标记字段缺失、同名异物或无法唯一匹配，并说明证据限制。所有实际字段差异都要纳入台账问题详情，逐项列出报告值、台账值和来源，并关联问题编号与截图；同一规则/同一表的相关差异可合并列项，但不得省略任何设备或差异，也不能只写在普通对照表中或被续期/更新解释替代。

时间关系要单独报告：R14 仅核设备使用有效期/停用状态；R15 仅核校准有效期/校准状态。逐项分别给出报告字段与台账字段一致性，以及检测日期是否处于各自有效期内。校准字段一致性（报告记载与台账原值是否相同）和检测日期的历史有效性必须分别给出独立结论，不能把一项结果替代另一项。新版/续期记录可能解释台账为何使用较新日期，但不会消除报告与台账原始字段的实际差异；按用户要求将字段不一致单独列为台账问题，逐字列出报告值、台账值、来源和差异。检测日期是否处于当时适用的历史有效期仍须另行核查；不能因新版续期就推定历史日期有效，也不能把字段一致当作日期有效，或把日期有效当作字段一致。列出实际日期、有效期起止与来源；不得把 R14 与 R15 字段相互替代。依完整规则作结论；资料不足时明确标记待补证或无法核实，不得臆造日期、周期、设备对应关系或条款。

## 报告、问题与证据格式

完整输出既有模板的全部章节及 R01-R19 覆盖表，每条规则均有结果、证据位置或不适用/待核实理由。逐项目资料矩阵和设备台账明细作为补充章节。所有结论由模型完成。

新项目问题使用 `### F-NNN-MMM [等级] 标题（规则号）`，全局汇总问题使用 `F-000-001` 等。各数字段至少三位并左侧补零，位数随实际序号增加、不设最大值；历史原稿中的旧式 `F-PPPNNN` 六位连写编号可按原编号引用。问题详情必须包含 `**页码**：第 N 页`（使用 `## Page N` 的 PDF 实际页序；每个问题给出确定页码，多页逐一列明）、位置、`**原文上下文**`（保留问题前后语境及原文）、违反要求、影响、整改建议、关联问题和证据。印刷页码可另列说明。可定位的报告证据使用对应完整问题编号作为 `evidence/` 图片文件名及引用，路径与现有截图及渲染程序兼容。标准和台账证据注明资料引用 ID、原文件名、页码或工作表，以及标准号/版本/条款、设备编号等足以定位记录的实际标识和所引原值；不强制重述行号或单元格坐标，若提供坐标则逐字照录。问题自身的极值和数量汇总在返回前须与所引用原文逐项核对，不一致时按原文重核并修正。不要把推测写成原文或事实。

最终总评应由模型根据完整规则结果和问题作出，并与问题清单、覆盖表保持一致；不得声称本地脚本复算或判定了任何业务结论。
