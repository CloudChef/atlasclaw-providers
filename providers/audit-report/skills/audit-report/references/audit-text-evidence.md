# 仅文本证据边界

本任务提交脱敏报告的原生提取文本、PDF 物理页标记、完整本地解析的 Excel/其他资料正文及其来源位置；页面图像/照片由独立视觉模型逐页核查，核查记录以 Mxx 资料形式提交。当前审核请求仅提交脱敏原生文本、物理页码及解析资料，不把页面像素直接交给文本模型。所有规则仍须逐项评估；所有业务判断由 LLM 依据本次文本、材料和视觉核查记录作出，本地只读取、解析、保留页码/单元格来源位置、切分和排版。

- 只能依据本次实际提交的文字、页码、材料和视觉核查记录作事实陈述。文本模型不得声称看过图片、照片、签名、印章或仪表图像；引用视觉记录时必须带页码/区域，并区分记录中的可见事实与推断。
- 对依赖图像的规则或事项（包括签名/印章、方法与照片条件对照、照片 AI 标记），若视觉核查记录没有明确可辨认的结论，按规则单独给出“待复核/无法核验”，不得因没有记录就判原报告缺照片/缺签章，也不得伪造通过或不通过结论。
- R33 要求把方法条件与照片中的实际设备/仪表读数对照。视觉记录中的照片标题、曲线标题或功能/电参数表工况不能替代照片实读；没有可读读数时，R33 视觉对照标“待复核”。可另述文本观察，但不能根据不同阶段条件或未见图表断言照片/方法不符合，也不能仅因同一视觉证据未提交就把 R45/R41 写成已证实未执行或不合格；只有文本直接支持时才按相应规则判定。
- 目录识别和文本分段请求没有提交 PDF 页面图像、照片像素或截图；视觉核查记录只在项目/汇总阶段以 Mxx 资料提交，不能把视觉记录当作目录阶段的正式页覆盖证据。
- 脱敏遮挡、文本提取未包含字段、PDF 文本断行/字符顺序异常，均不能单独证明原报告字段或内容缺失。区分“文本中未提取/无法核查”和“原报告明确未载明”；只有本次文字直接支持时才可陈述后者。不要把脱敏或解析产物的缺口判成原件缺陷。
- 对生产、收样、检测、签发等日期字段，若脱敏或提取使其在本次材料中不可见/被遮挡/被替换，只能说明当前材料无法核验，不得称原报告未载明或仅据此要求更正/补写原件。只有可靠来源直接显示字段为空、被明确标为缺失，或其他直接证据确认未载明时，才可作原报告缺失结论。仍须按规则比较本次可读取的全部日期及各阶段区间；已由可读日期直接证明的逆序或超期仍按规则判定，不因其他日期字段不可核验而弱化或删除。
- 对表格数值，利用实际提交的页文本、表头、样品标识、工况和单元格来源标记逐项核对。只有当原文足以确定行列关系和单位时才作确定的数值判断；断行、列序或单元格归属不清时逐项说明限制，不按数值合理性猜测重排、不修复歧义值、不将定性 OK/Pass 转为数值。
- 全部测量比较、极值、日期、设备匹配、标准条款适用性及规则结论都由 LLM 作出。标准目录/名称/编号不替代标准正文。必要条款或证据未提交时，保留具体限制，不虚构要求或无保留判通过。
- 只使用本次提交的当前源文与资料，不复制或依赖先前模型初审、视觉核查、数值核查或候选报告；这类旧阶段原稿不随本请求提供。
- 报告引用使用本次提交的 PDF 实际页码与足以核实问题的完整原文上下文，不设引用长度上限。表格资料标明 Mxx、原文件名、工作表、足以定位记录的原始标识（例如设备编号）和所引原值；输出中不强制重述单元格坐标。若自愿引用解析提供的坐标，必须逐字照录完整坐标/范围及对应原值，不得从序号或相邻记录推算，也不得用范围起点代替实际值位置。
